# MTProto Finder — iOS (пре-альфа v0.pa1t)

SwiftUI-приложение: поиск MTProto/SOCKS5 прокси для Telegram с реальным TCP-пингом.

## Статус
ПРЕ-АЛЬФА. Сборка .ipa возможна только на macOS с Xcode 15+ (на Linux iOS-бинарники не собираются).

## Сборка
1. Открыть `MTProtoFinder.xcodeproj` в Xcode на любом Mac
2. Выбрать свой Signing Team в настройках таргета
3. Product → Run (симулятор/устройство) или Product → Archive для .ipa

Требования: iOS 16+, Xcode 15+. Иконка — logo.png в Assets.
